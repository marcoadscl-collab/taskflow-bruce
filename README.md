# TaskFlow · Bruce

Planificador personal en un único archivo HTML. Sin backend, sin cuentas, sin dependencias externas.
Los datos viven en el `localStorage` del navegador de cada dispositivo.

- `index.html` — la aplicación completa (incluye el ladrido de Bruce incrustado en base64).

## Qué incluye

- Captura rápida en lenguaje natural: `Llamar a proveedor mañana 10:00 !alta #Proyecto`
- Vistas: Hoy, Agenda (calendario diario), Próximos, Proyectos (kanban), Notas, Hábitos, Resumen, Perfil
- Subtareas, recordatorios con alarma y notificación del sistema
- Bruce: asistente local que hace el repaso del día, avisa los hábitos y ladra
- Modo claro / oscuro, responsive, atajos `N` · `M` · `/` · `Esc`
